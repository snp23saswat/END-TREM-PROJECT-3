# End-Term Project 3 — Kanban Board

A React + Vite Kanban board app for tracking academic workloads and tasks across a five-stage lifecycle: **Backlog → To Do → In Progress → Review → Done**.

**Live demo:** https://end-trem-project-3.vercel.app

## Features

- Interactive Kanban board — move tasks between stages
- Student-focused workflow for assignments, projects, and daily tasks
- Clean, responsive interface for desktop and mobile

## Tech Stack

- **Frontend:** React 18
- **Build tool:** Vite

## Getting Started

```bash
git clone https://github.com/snp23saswat/END-TREM-PROJECT-3.git
cd END-TREM-PROJECT-3
npm install
npm run dev
```
